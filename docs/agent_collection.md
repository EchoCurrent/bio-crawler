# Agent 采集规范 (所有采集子 agent 必读)

## 任务模式
广度优先情报搜集。你是「生物医学」大类下一个子方向的采集员。
时间窗口：**不限**（首轮把广度铺开），优先近 2 年内的内容。
目标：每个子方向 **30-40 条**有效条目。

## 工作流程（至少 3 轮扩展）
1. 第 1 轮：用给定的子方向种子词做 web_search，收集候选条目。
2. 第 2 轮：从第 1 轮结果里找新线索——重要论文的标题、机构名、人名、临床试验编号、
   公司名、政策名等，改写成新的查询词继续搜。
3. 第 3 轮：对高价值主题（ relevance=high 的）再做一轮针对性扩展，比如找同一事件的
   其他来源报道（交叉验证素材）。

## 输出：JSONL 文件（每行一条，UTF-8）
写入你的专属输出文件（父 agent 会在任务里给你确切路径）。**每写完几条就追加保存一次**，
防止中途失败丢数据。用 Python 或 shell 追加均可。

每行一个 JSON 对象，字段必须齐全：
```json
{
  "title": "条目标题（用原文标题，可短截断到80字）",
  "url": "真实URL，必须是你实际在搜索结果或网页里看到的",
  "source": "来源名称，如 Nature / BioArt / 生物谷 / FDA官网 / 公司名",
  "source_type": "journal | website | wechat | news | official | preprint",
  "category": "生物医学",
  "subtopic": "子方向名（任务里给你的那个）",
  "summary": "一句话中文摘要，50字以内，说清是什么/为什么重要",
  "relevance": "high | medium",
  "published_time": "YYYY-MM-DD 或 空字符串",
  "via": "发现它的检索词或路径，如 'sirtuin 抗衰老 临床试验'"
}
```

## 铁律
1. **绝不编造 URL**。只记录你真实在搜索结果或抓取页面里见过的链接。不确定就丢弃。
2. **相关性过滤**：与生物医学无关的不要；明显是广告/招聘/会议通知的不要。
3. **来源多样性**：单一来源（比如全是百度知道）的条目比例不要超过一半；
   优先学术期刊、机构官网、权威媒体、知名行业公众号。
4. URL 里如果带明显的 tracking 参数可以保留原始链接，不用清理。
5. 标题和摘要**用中文**（原文是英文的话，标题保留英文原题，summary 写中文）。

## 完成后
向父 agent 汇报（中文）：输出文件路径、条目数、relevance=high 的数量、
主要覆盖了哪些来源/站点、遇到的问题。不要把 JSONL 全文贴回来。
